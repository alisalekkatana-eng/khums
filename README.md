# حساب خمس

برنامه‌ی محاسبه‌ی خمس بر اساس فتاوای آیت‌الله مکارم شیرازی: ثبت درآمد، مخارج و خرید، پرداخت‌ها، سال خمسی، شأن‌سنج و بات پرسش‌وپاسخ.

> ابزار کمکی است و جای رساله یا نظر دفتر مرجع را نمی‌گیرد. برای موارد مهم از دفتر ایشان (makarem.ir) بپرس.

## دو روش استفاده

### ۱. نسخه‌ی وب (GitHub Pages)
فایل `index.html`؛ داده‌ها فقط در مرورگر کاربر (localStorage) می‌ماند و هیچ‌جا ارسال نمی‌شود.
بات با کلید API خود کاربر مستقیم از مرورگر به انتروپیک وصل می‌شود. کلید فقط در همان مرورگر ذخیره می‌شود.

### ۲. نسخه‌ی محلی (پایتون)
```
python khums.py
```
فقط Python 3.8 یا بالاتر لازم است. داده‌ها در پوشه‌ی `~/.khums` ذخیره می‌شود (مسیر با `KHUMS_HOME` عوض می‌شود). کلید را در تب «بات» بده یا `ANTHROPIC_API_KEY` را تنظیم کن. مدل با `KHUMS_MODEL` (پیش‌فرض `claude-sonnet-5-5`) قابل تغییر است.

## انتشار به‌عنوان سایت عمومی (بات برای همه فعال)
برای اینکه بازدیدکننده‌ها بدون کلید خودشان از بات استفاده کنند، باید `khums.py` روی یک سرور اجرا شود که کلید تو را نگه می‌دارد.
1. مخزن را در گیت‌هاب بگذار.
2. در Render (یا Railway، Fly.io) یک Web Service از همین مخزن بساز. فایل `render.yaml` و `Dockerfile` آماده‌اند.
3. متغیرهای محیطی: `KHUMS_HOSTED=1` و `ANTHROPIC_API_KEY=<کلید تو>`.
4. بعد از دیپلوی، آدرس HTTPS سرویس را می‌گیری؛ دامنه‌ی دلخواه را هم از تنظیمات همان سرویس وصل کن.

در حالت عمومی:
- اطلاعات مالی هر بازدیدکننده فقط در مرورگر خودش می‌ماند و روی سرور ذخیره نمی‌شود.
- فقط متن سؤال و خلاصه‌ی اعداد و شأن او هنگام پرسیدن از بات به سرور و از آنجا به انتروپیک می‌رود.
- برای جلوگیری از هزینه‌ی ناخواسته، سقف استفاده هست: `KHUMS_RATE` (پیش‌فرض ۳۰ درخواست در ساعت برای هر IP) و `KHUMS_DAILY` (پیش‌فرض ۵۰۰ در روز).
- در کنسول انتروپیک هم برای کلید سقف هزینه‌ی ماهانه بگذار.

## دیپلوی نسخه‌ی ثابت روی GitHub Pages
1. مخزن جدید بساز (برای Pages رایگان، مخزن باید عمومی باشد).
2. فایل‌ها را push کن:
   ```
   git init -b main
   git add .
   git commit -m "حساب خمس"
   git remote add origin https://github.com/USERNAME/khums.git
   git push -u origin main
   ```
3. در مخزن: Settings ← Pages ← Source را روی **GitHub Actions** بگذار.
4. بعد از اجرای workflow، آدرس `https://USERNAME.github.io/khums/` فعال می‌شود.

## نکات مهم
- **هیچ‌وقت کلید API خودت را داخل کد یا مخزن نگذار.** هر کاربر کلید خودش را در برنامه وارد می‌کند.
- کلیدی که در مرورگر می‌گذاری برای استفاده‌ی شخصی مناسب است؛ ترجیحاً کلیدی با سقف هزینه بساز.
- اطلاعات مالی کاربران در مخزن ذخیره نمی‌شود. از تب «محاسبه» پشتیبان بگیر، چون داده‌ی مرورگر با پاک شدن از بین می‌رود.
- پیش از انتشار عمومی، یک مجوز (License) انتخاب کن.
